# IndexNow

ZeroToHosting sends changed public URLs to IndexNow after a successful
production build on Vercel.

## How it works

- The public ownership key is stored at
  `https://zerotohosting.com/005a4fef226988853271079c29665750.txt`.
- `npm run postbuild` runs the IndexNow script only when Vercel sets
  `VERCEL_ENV=production`.
- The script reads the sitemap generated by the current build and submits the
  URLs with the newest `lastmod` date.
- An IndexNow outage logs a warning but never blocks the website deploy.

## Useful commands

- `npm run indexnow:check` validates the key and built sitemap without sending
  anything.
- `npm run indexnow` submits every URL in the live sitemap. Use this after
  rotating the key or when an automatic submission needs to be retried.

Keep each edited page's `lastModified` value current. IndexNow does not replace
the XML sitemap or Google Search Console; Google does not use IndexNow.
